如何验证？

  1. 游戏开始前，服务端下发 serverSeedHash（SHA-256 承诺）
  2. 每局结束后，下注响应中的 provablyFair 会公开 serverSeed
  3. 在本页填入种子与 nonce（即 roundId），点击验算
  4. 若 Hash 与 Roll 均匹配，则证明结果未被篡改
