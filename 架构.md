## 四、 核心组件技术选型矩阵

| 分层 | 组件 / 框架 | 关键作用与配置规范 |
| :--- | :--- | :--- |
| **前端引擎** | Cocos Creator 3.8.x | TypeScript 驱动，单局纯表现层，严禁本地计算判定。 |
| **核心服务** | Go-Zero | 纯 Go 高并发微服务框架，内置限流、熔断与高并发缓存支持。 |
| **管理后台** | Sponge + Vue 3 | 统一 Go 生态脚手架，负责系统配置、商户入驻、Casbin RBAC。 |
| **主业务库** | MySQL 8.0+ | 字符集 `utf8mb4`，时区 `UTC`，存储商户、权限、游戏字典及账单。 |
| **缓存/锁** | Redis Cluster | 负责分布式排他锁（单用户单局并发拦截）、幂等防刷、实时大额榜。 |
| **事件中枢** | Kafka | 分区键绑定 `UserID`，开启 `Snappy` 压缩，解耦注单持久化与大奖广播。 |
| **日志分析** | ClickHouse | 列式存储承载海量注单，支持秒级计算全服实际 RTP 偏差与大盘数据。 |
